# dtxpt default skin

This is the shipped default skin descriptor for the BocuD compatibility pass.

The current default skin is procedural: gameplay lanes, notes, receptors, hit bursts, HUD, and menu colors are generated by dtxpt's Bevy systems instead of loading bitmap lane skins. The descriptor gives the runtime a stable skin identity now, while later phases can add drop-in PNG/OGG assets under this folder without changing save data.

`judgement_font = "system-cjk"` means UI text uses the CJK-capable font loaded by `src/ui/fonts.rs` when available, so Japanese song metadata renders correctly.
